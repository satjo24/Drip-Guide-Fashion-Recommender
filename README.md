# 💧 Drip Guide – Smart Fashion Recommender

A fashion recommendation system built using Python, Pandas, and Streamlit.

## Features
- Personalized outfit recommendations
- Filter by Gender, Season, Color, and Price
- Trending fashion picks
- Smart fashion suggestions

## Technologies Used
- Python
- Pandas
- Streamlit

## How to Run

```bash
pip install streamlit pandas
streamlit run app.py
```
